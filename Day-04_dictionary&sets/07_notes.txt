Topic: Dictionary & set

what learn:
1. Dictionary:
   syntax: 
     dict1={
        "name":"rohit",
        "age" : 23,
        "cource":"Python"
        "address":{           -- sub dictionary (Dictionary in side of Dictionary)
           "city":"thane",
           "state":"Maharastra",
           "pin_code":"400604"
        }
     }

2. Dictionary methods:
   - print(dict1["name"])    #returns error if the key is not present in dictionary--interview que
   - print(dict1.get("name"))#returns none if the key is not present in dictionary--interview que
   - print(dict1.keys())      #it returns all keys from the dictionary
   - print(dict1.values())    #it returns all the value of the keys from dictionary
   - print(dict1.items())    #it returns dictionary like a tuple form


3. set and Empty set:
   syntax: 
     a={5,6,3,4,2,1}  
     
   - a={}  --this is not an empty set this is a empty dictionary
   - b=set()   --this is a empty set

4.set methods: a is a set
  - a.add((5,6))   #tuples are immutable, so they can be added to a set
  - a.add(3)       
  - b.remove(3)
  - c.pop()
  - d.clear() #it return empty set : set()
  - e = a.union(b)  union set --it returns all elements from both sets 
  - f = a.intersection(b) intersection set --it return similar value from both set
  
Mistakes:
  - a.add({})      --this return error , cannot add dictionary in set ,dict is mutable
  - a.add([2,3,4,9])--this return error , cannot add list in set ,list is mutable
  - a.add(3,4,7)   --it return error , you can add 1 element at a time
  - b.remove()    --it return error , you have to put one element to remove
  - b.remove(3,4) --it return error , you can remove one element at a time
  - c.pop(7)      --it return error , dont need to define element to remove mostly from end of the set of the last one added

Important:
  Dictionary
  - it is unordered
  - it is mutable
  - it is indexed
  - it cannot contain dublicate key
  set
  - set is a collection of non repetative elements
